# ใช้หน้า Print Studio — SCCUSTOM v1.1.4

1. เปิดงานแล้วไปที่ **ขั้นที่ 3 จัดแบบพิมพ์** แถบบนแสดงลูกค้า รหัสงาน รุ่นปากกา แบรนด์สำหรับหัวเอกสาร และสถานะบันทึกในเครื่อง
2. ใน **ตั้งค่างาน** เลือกโหมดโลโก้ ข้อความ หรือทั้งสองอย่าง และคลิกสีด้ามเพื่อเปลี่ยนเฉพาะภาพตัวอย่าง หากต้องแก้สีที่สั่ง จำนวน หรือหมึก ให้กด **แก้สีและจำนวน** เพื่อกลับไปขั้นที่ 2
3. ใน **ดูชิ้นงาน** เลือกดูบนด้ามหรือขยายพื้นที่พิมพ์ มุมขยายแสดงกรอบและหน่วยมิลลิเมตร ลากแบบเพื่อเลื่อนภายในกรอบ ภาพบนจอไม่ใช่การแสดงขนาดจริง 1:1
4. **ปรับแบบ** แสดงเครื่องมือตามโหมด ใช้ขนาดรวม ระยะระหว่างชิ้น และปุ่มจัดกึ่งกลาง ค่าพิกัดและลำดับข้อความอยู่ใน **ปรับตำแหน่งเพิ่มเติม** ส่วนระยะเผื่อและค่าจากทีม Design อยู่ใน **สเปกพื้นที่พิมพ์**
5. กด **ตรวจแบบก่อนส่ง** เพื่อเข้าไปดูฟอร์มตรวจและส่งออกเดิม แถบล่างแยกว่าตำแหน่งแบบอยู่ในกรอบหรือไม่ กับว่าส่งออกไฟล์ผลิตได้หรือยัง ทั้งสองอย่างไม่ใช่ผลเดียวกัน
   
ก่อนอัปเดตบน GitHub ให้เก็บไฟล์ตั้งค่าแบรนด์ โฟลเดอร์โลโก้ และโปรไฟล์ผลิตฉบับที่ใช้อยู่ หากเป็นการติดตั้งใหม่ โปรไฟล์ Quantum 341224 ในแพ็กเกจเป็นตัวอย่าง จึงใช้ทดลองจัดแบบได้แต่ยังไม่ปลดล็อกไฟล์ผลิต ดูรายละเอียดใน [คู่มือตั้งสเปกกรอบ](PRODUCTION_LAYOUT_SETUP.md)
