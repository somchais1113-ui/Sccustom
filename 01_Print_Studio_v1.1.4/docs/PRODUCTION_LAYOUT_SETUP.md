# ตั้งกรอบปลอดภัยสำหรับจัดแบบพิมพ์ — SCCUSTOM V1.1.3

## ทีม Design ตั้งสเปกที่ไฟล์เดียว

เปิด `config/print-profiles.js` กำหนดหนึ่งรายการต่อรุ่น / วิธีพิมพ์ / ตำแหน่ง โดยใช้ `productId` และ `method` ตรงกับ Product Master และระบุ:

- `locationId` รหัสตำแหน่งพิมพ์ เช่น `barrel` และ `locationLabel` ชื่อที่ Sale เห็น
- `areaMm: {width, height}` พื้นที่พิมพ์นอกของตำแหน่งนั้น ระบุเมื่อขนาดต่างจาก Product Master
- `marginsMm: {left, right, top, bottom}` ระยะเผื่อจากกรอบนอกทั้งสี่ด้าน ใส่ 0 ได้หากพื้นที่ที่โรงงานให้เผื่อไว้แล้ว ห้ามหักซ้ำ
- `minGapMm` ระยะขั้นต่ำระหว่างกรอบโลโก้กับกรอบข้อความ กำหนดตามแบบที่ทีมอนุมัติ ไม่ใช่เกณฑ์เส้นขั้นต่ำ
- `revision` เวอร์ชันสเปก และ `verified: true` หลังทีม Design ยืนยันค่ากับฝ่ายผลิตแล้วเท่านั้น

แพ็กเกจมีโปรไฟล์ตัวอย่าง Quantum 341224 เพียงเพื่อดูการจัดวาง ไม่ใช่สเปกโรงงาน ระบบอนุญาตให้ดูแบบและส่งให้ Design ตรวจ แต่ยังล็อก Production SVG/ZIP เมื่อโปรไฟล์ไม่ยืนยัน ไม่พบ หรือไม่ถูกต้อง ถ้าไม่มีตำแหน่งอื่นในไฟล์ตั้งค่า ระบบใช้ตัวด้ามเป็นหน้าดูแบบเริ่มต้น ตำแหน่งที่ไม่ใช่ตัวด้ามแสดงงานในกรอบพิมพ์ ไม่เอาแบบไปแปะทับภาพด้ามผิดตำแหน่ง

## ทีม Sale จัดแบบในขั้นที่ 3

1. เลือก **โลโก้**, **ข้อความ** หรือ **โลโก้ + ข้อความ** และใส่องค์ประกอบตามโหมด
2. ปรับขนาดรวมโดยไม่ยืดรูป เลื่อนด้วยการลากหรือกรอกค่าเป็นมิลลิเมตร หรือกด **จัดกึ่งกลางกรอบปลอดภัย**
3. โหมดโลโก้ + ข้อความจัดวางแนวนอน สลับก่อน/หลังได้ ปรับความสูงข้อความเทียบกับโลโก้และระยะห่างได้ ระยะนี้วัดจากกรอบแต่ละชิ้น ไม่ใช่ขอบหมึก หาก SVG ต้นฉบับมีพื้นที่ว่าง ขอบหมึกอาจห่างมากกว่าค่าที่ตั้ง ควรขอ SVG ที่ตั้ง artboard ตรงกับชิ้นงานจาก Design
4. ข้อความรองรับหนึ่งบรรทัด เลือกฟอนต์สำหรับดูตัวอย่าง ปรับช่องไฟตัวอักษร และเลือกไฟล์ TTF/OTF จริงเพื่อแปลงเป็นเส้น เมื่อแก้ข้อความ ฟอนต์ หรือตัวเลขช่องไฟ ให้แปลงใหม่ ระบบใช้การจัดรูปตัวอักษรทั้งบรรทัดและขยับเป็นกลุ่ม ถ้าแมปกลุ่มสระหรือวรรณยุกต์ไม่ได้ ระบบจะไม่บังคับเว้นช่องไฟ ให้ตั้งเป็น 0% หรือส่ง Design ตรวจ
5. ข้อความใช้หมึกช่องที่ 1 ของแต่ละสีด้าม งานเวกเตอร์ต้องมีจำนวนสีตรงกับหมึกที่ตั้งไว้ PNG/JPG/WebP ใช้ดูตัวอย่าง ไม่แปลงเป็นโลโก้เวกเตอร์อัตโนมัติ

## งานที่ต้องแก้รายละเอียด

กด **บันทึกรอตรวจและดาวน์โหลด ZIP ให้ Design** แล้วส่ง ZIP เอง ภายในมีใบสรุปจุดตรวจ ตัวอย่าง SVG พร้อมกรอบ และ PROJECT.json เปิดแก้ต่อได้ ไม่ใช่ไฟล์ส่งผลิตและระบบไม่ได้ส่งข้อความให้ทีมอัตโนมัติ หากต้องแก้เส้นหรือช่องไฟภายในรูปโลโก้ ใช้ไฟล์ต้นฉบับของลูกค้าในโปรแกรมเวกเตอร์ แล้วอัปโหลดฉบับที่อนุมัติกลับเข้ามา กด **บันทึกว่าได้รับผลตรวจแล้ว** เมื่อทีมตรวจเสร็จ เป็นการบันทึกในงาน ไม่ใช่ระบบล็อกอินหรืออนุมัติด้วยลายเซ็นของ Design

เส้นไกด์ไม่ติดใน Production SVG/ZIP ขนาดส่งออกอิงกรอบนอกที่ 1:1 ส่วนกรอบปลอดภัยใช้คุมตำแหน่งงานข้างใน ยังไม่ใช่การตรวจเส้นบาง ช่องปิด ตัวอักษรเล็ก หรือสีพิมพ์ 2–3 สีโดยอัตโนมัติ
