# ตั้งโลโก้หัวเอกสาร SCCUSTOM v1.1.2

## สำหรับคุณสมชายหรือผู้ดูแล Repository

ถ้าเคยตั้งโลโก้ใน v1.1.1 แล้ว ให้เก็บ `config/brand-logos.js` ฉบับของคุณและไฟล์โลโก้เดิมไว้ ไม่ต้องตั้งใหม่และไม่ต้องนำไฟล์ตั้งค่าตัวอย่างใน ZIP ไปทับ

1. เตรียมโลโก้ที่แบรนด์ใช้อยู่จริง เป็น SVG ที่แปลงข้อความเป็นเส้นแล้ว หรือ PNG/WebP พื้นโปร่งใส
2. วางไฟล์ใน `assets/brand-logos/` ชื่อไฟล์พิมพ์เล็ก ไม่มีเว้นวรรค เช่น `elfen.svg` หรือ `master-art.png`
3. เปิด `config/brand-logos.js` และแก้เฉพาะค่าด้านขวาในแถวของแบรนด์ โดยคงรหัสด้านซ้ายไว้

```js
  quantum: 'assets/brand-logos/quantum.svg',
  elfen: 'assets/brand-logos/elfen.svg',
  'master-art': 'assets/brand-logos/master-art.png',
```

4. Commit ทั้งไฟล์โลโก้และไฟล์ตั้งค่าไปที่ GitHub สาขาที่ใช้ Deploy หลังเว็บอัปเดต ให้เลือกแบรนด์แล้วเปิด Customer Proof ตรวจหัวเอกสารอีกครั้ง

| แบรนด์ | ชื่อไฟล์ที่แนะนำ |
| --- | --- |
| Quantum | `quantum.svg` |
| Elephant | `elephant.svg` |
| Elfen | `elfen.svg` |
| Uni | `uni.svg` |
| Mitsubishi | `mitsubishi.svg` |
| Master Art | `master-art.svg` |
| Ultimatum | `ultimatum.svg` |
| Artifact | `artifact.svg` |
| SCCUSTOM | `sccustom.svg` |

หากใช้ PNG หรือ WebP ให้ระบุนามสกุลตรงกับไฟล์จริง ตัวพิมพ์เล็กและใหญ่ต้องตรงกันกับชื่อบน GitHub หากเปลี่ยนโลโก้แล้วเว็บยังแสดงไฟล์เดิม ให้ลองรีเฟรชแบบไม่ใช้แคช หรือใช้ชื่อเวอร์ชันใหม่ เช่น `quantum-v002.svg` และเปลี่ยนพาธให้ตรงกัน

## สิ่งที่ Sale เห็น

- ในดรอปดาวน์ เลือกได้เฉพาะแบรนด์ที่ตั้งโลโก้แล้ว ชื่อและรูปของแบรนด์ที่เลือกแสดงเหนือดรอปดาวน์ และใช้ในตัวอย่างเอกสารด้วย
- ถ้ายังไม่ตั้งค่า หรือพาธเปิดรูปไม่ได้ จะมีข้อความบอกและเลือกไม่ได้
- ไม่มีการใช้ชื่อแบรนด์แทนโลโก้ในเอกสาร หากงานเดิมเคยใช้โลโก้รายงาน ให้เลือกแบรนด์ที่ตั้งไว้ใหม่ก่อนเปิด PDF
- โลโก้ลูกค้าสำหรับสกรีนยังอัปโหลดได้ในขั้นที่ 3 โลโก้มุมซ้ายบนเว็บและไฟล์ PDF ที่เคยดาวน์โหลดแล้วไม่เปลี่ยนตามค่ากลาง
- การแก้ค่ากลางอยู่ที่สิทธิ์แก้ Repository ไม่มีหน้าอัปโหลดค่ากลางในเว็บ
